Provisional contract under test

      
    
        
  • Capability is frozen before execution. Missing Windows support is unexpected not runnable; current Linux absence is expected not runnable.
    • 
        
  • After declaration, lost focus, wrong-window ambiguity, an unexpected approval, or inaccessible screenshot bytes cannot be downgraded to not runnable.
    • 
        
  • Observer failures make affected mandatory assertions not reached and the aggregate QA verdict inconclusive; they are not Booley product failures.
    • 
        
  • A visually wrong product state with trustworthy evidence is a fail, yet it may still prove the observer can capture failures correctly.
    • 
        
  • The target frame contains only the named VS Code window. Credentials, account identity, billing, notifications, and unrelated desktop content are excluded before capture, not redacted later.
    • 
        
  • Human review is asynchronous. It validates the observer qualification and audits the original artifact; it never repairs a missing runtime capture or changes the automated Scenario outcome.

- The Mutation Flow now also gives an unsized literal its plus-one Mutant when the new value
  fits the narrowest width the literal's value is used at: `a + 1` with an 8-bit `a` gains
  `a + 2`, while `flag <= 1` with a 1-bit `flag` still only becomes `0`. The Mutant generator
  is now version 6: existing Mutant IDs stay and the candidate set grows, so the same `--seed`
  and `--count` may select different Mutants than before.

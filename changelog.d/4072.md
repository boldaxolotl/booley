- `booley feedback add`, `friction`, and `win` now require `--origin`
  (`setup`, `bug`, or `impression`); the old default of `setup` is gone, so
  scripts that omit it must pass one. `booley feedback report` now writes two
  local reports: `.booley/SETUP-REPORT.md` holds only the entries logged by a
  setup run, and `.booley/FEEDBACK-REPORT.md` holds everything logged through
  `/booley-feedback`, so a bug report no longer lands in your setup report. A
  report whose content did not change is not rewritten, and
  `--user-report-path` now writes only the setup report.

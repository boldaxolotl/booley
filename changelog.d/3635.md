- The Mutation Flow no longer simulates Mutants that provably change nothing. On a Target
  simulated with Verilator, a Mutant whose generated C++ equals the baseline's is replaced
  by the next candidate in the selection order, so the run still scores `--count` Mutants
  unless the candidates run out. The report does not list the dropped Mutants; the Record's
  detail lists their IDs under `equivalent_dropped`. Icarus Targets simulate every Mutant.
  The `+`/`-` swap is no longer a Mutant where both results are equal at the expression's
  width. The Mutant generator is now version 4, so the same seed can select different Mutants
  than before, and a Verilator Target's identity records the Verilator version.

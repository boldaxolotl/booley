- Fixed B-Wave help: `signal`, `wave` and `distance` no longer claim JSON
  requests exit 2 (they return JSON), `list --tree` says it is text only, and
  the wrapper parser's command list names `overview`. A waveform store that
  cannot be loaded now names the cause and how to rebuild it. A truncated
  store, or an FST with trailing bytes after its last block, that used to load
  and answer every query with empty data now fails to load (exit 1).
  `bwave register` prints the cause (it still registers the alias), and the
  simulation flow's trace check reports the store as unreadable.

- In a Project, `booley auth --status` now reports every Agent CLI in `[agent] clis`, default
  first, each under its own `auth` policy; `--cli <name>` reports one. It exits nonzero only
  when no reported CLI has a usable credential. `booley init`'s agent authentication step now
  checks every allowed Agent CLI and warns for one without a credential. `booley init --check-only` exits 1 for it only when
  the CLI is required: the default, or one a `[models]` entry runs a Specialist on.

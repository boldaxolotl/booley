- The Reviewer no longer special-cases a `fw/` directory. Both Reviewers now
  read every project file outside their opposite category as context, firmware
  included, in and outside Goal Mode, except HDL files no `.core` fileset
  declares. A `fw/` source is RTL only when the RTL fileset lists it, and a
  review `scope` on a firmware file follows the usual scope rules instead of
  being refused.
- Without a `.core`, the default RTL and testbench directories are `rtl/` and
  `tb/` only; `fw/`, `util/`, and `data/` are no longer assumed. Doctor's
  `.core` security audit treats only the `.core`-derived directories as the
  agent-writable Scope.

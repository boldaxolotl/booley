- Breaking: `[agent] auth = "auto"` is retired. Booley refuses to load a `booley.toml`
  that sets it, as a string or as an `[agent.auth]` entry, and `booley doctor` fails on it
  and names the value to use. Replace it with `subscription` or `api_key`, or re-run
  `booley init`, which rewrites it from your credentials. A missing `auth` now bills the
  subscription even when an API key is exported, and `booley init --auth` takes only
  `subscription` or `api-key`.
  ([issue #4080](https://github.com/boldaxolotl/booley/issues/4080))

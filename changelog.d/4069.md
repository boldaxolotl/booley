- Breaking: `[jobs].memory_budget` is retired. The Memory Budget is always
  `[sandbox].memory` (or the installed memory) minus the measured reserve. While
  `booley.toml` sets the key, Flow and Specialist runs and every command that
  works on a Project except `booley doctor`, `booley upgrade`,
  `booley session` and `booley chat` refuse and name the key and its line, and
  `booley doctor` reports a FAIL with "set `[sandbox].memory` instead". Delete
  the line, or type `/booley-heal` in a Developer Agent chat to remove it, and
  size `[sandbox].memory` instead.
  ([issue #4069](https://github.com/boldaxolotl/booley/issues/4069))

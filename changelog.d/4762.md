- Fixed `bwave find` and `bwave sample` treating a Marker given to
  `--before` or `--after` differently from its cycle: the same refusals and
  exit code now apply (`--before hs --count` runs like `--before 25 --count`).
  The `--before=hs`, `--time=hs:he`, `-ths:he` and `value --at=hs` spellings
  now resolve the Marker too, and `bwave diff -s PATTERN hs he` resolves `hs`
  and `he` instead of the pattern.

- A Project that moves from `[agent] auth = "auto"` to `"subscription"` now keeps its Sandbox's
  agent state volume (in-Sandbox login, transcripts and plans) across `booley session refresh`;
  before, the switch started an empty volume. A Sandbox already issued for `subscription` keeps
  its own volume. If the shared volume holds an API key, the start is refused with a message
  naming the file to fix.

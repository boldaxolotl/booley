- The Developer Agent's MCP server is now marked by `BOOLEY_MCP_DEVELOPER_AGENT=1`
  instead of `BOOLEY_MCP_MODE=interactive`. Re-issue each Project's Sandbox
  (`booley session refresh`, or the step `booley doctor` names): a Sandbox issued
  before this change is reported stale. Session MCP logs and Standalone Job logs
  now go to `job_logs/` in the Booley Directory instead of `.interactive_logs/`.
  Old logs are not moved; `booley doctor` warns about a leftover
  `.interactive_logs/` and prints the command that deletes it
  ([#4547](https://github.com/boldaxolotl/Booley/issues/4547)).

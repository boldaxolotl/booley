- Sandbox remedy messages now name the steps that
  [Applying Sandbox changes](https://booley.dev/docs/sandbox/#applying-sandbox-changes)
  documents for how you open the Sandbox, whether its container is running or
  stopped. A VS Code Sandbox is told to run `booley init` and use
  **Dev Containers: Rebuild Container**, never `booley session refresh` or
  `booley init --force`. `sandbox.image-stale` and `upgrade.runtime-stale` name
  the same steps, and `upgrade.runtime-stale` says to recreate the Sandbox
  before `/booley-heal`.

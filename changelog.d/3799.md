- `booley init` now has Git check out again the files that are CRLF only because of the
  checkout, instead of rewriting them itself, and it also pins `core.eol=lf` in the
  repository. A file that differs from Git's copy by more than line endings is left
  as it is, and init lists it. This fixes the repair failing on Git for Windows when
  the repository has `* text=auto`, and a file that another file is hard-linked to no
  longer blocks the repair. A non-repository is also skipped when Git speaks another
  language.
  ([issue #3799](https://github.com/boldaxolotl/booley/issues/3799))

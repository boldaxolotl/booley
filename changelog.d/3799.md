- `booley init` now converts CRLF checkouts back to LF through Git itself, and sets
  `core.eol=lf` in the repository unless it is already `lf`. This fixes the repair failing
  on Git for Windows when the repository has `* text=auto`. A file that Git cannot
  re-create with LF endings, for example one that a Git filter changes on every checkout,
  is left as it is, and init lists it. A file that another file is hard-linked to no longer
  blocks the repair, and init recognizes a folder that is not a Git repository when Git's
  messages are localized.
  ([issue #3799](https://github.com/boldaxolotl/booley/issues/3799))

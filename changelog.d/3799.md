- `booley init` now has Git check out again the files that are CRLF only because of the
  checkout, instead of rewriting them itself, and it pins `core.eol=lf` in the repository
  when that is not already set. A file that differs from Git's copy by more than line
  endings, such as one a Git filter rewrites, is left as it is, and init lists it. This
  fixes the repair failing on Git for Windows when the repository has `* text=auto`, and a
  file that another file is hard-linked to no longer blocks the repair. Init also
  recognizes a folder that is not a Git repository when Git's messages are localized.
  ([issue #3799](https://github.com/boldaxolotl/booley/issues/3799))

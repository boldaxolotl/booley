- A Pre-Sim Command or a Mutation build or simulation that runs out of memory
  is now named like any other Job's kill. A kill at `[sandbox].memory` runs
  only that test, or that one Mutation run, again alone; a kill on the host is
  not retried and says how to free memory. A Mutant whose run is killed again
  counts as inconclusive instead of failing to build or being scored.

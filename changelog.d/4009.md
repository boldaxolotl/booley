- The Mutation Flow now reads widths, enum members, and signedness from the elaboration of
  the whole Target, with its top module and parameters, instead of each scope file alone with
  default parameters. A `+`/`-` swap or unsized plus-one Mutant now follows the width the
  Target gives, and a module with a parameter or an interface port no longer keeps its swaps
  when the Target shows them equal. A Target that cannot be elaborated as a whole falls back
  to the old per-file rules, and the report, `mutation-results.md`, and the manifest say so.
  The Mutant generator is now version 7: existing Mutant IDs stay for candidates both rules
  find, and the candidate set changes, so the same `--seed` and `--count` may select
  different Mutants than before.

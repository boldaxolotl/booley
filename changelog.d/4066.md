- Breaking: the Job queue has no limit. A Job that cannot start waits until it
  runs or is cancelled, instead of being refused as BLOCKED. `[jobs].queue_max`
  is retired: while `booley.toml` sets it, Flow and Specialist runs and every
  command that works on a Project except `booley doctor`, `booley upgrade`,
  `booley session` and `booley chat` refuse and name the key and its line, and
  `booley doctor` reports a FAIL. Delete the line, or type `/booley-heal` in a
  Developer Agent chat to remove it. The Dashboard no longer refuses Submit for
  a full queue.
  ([issue #4066](https://github.com/boldaxolotl/booley/issues/4066))

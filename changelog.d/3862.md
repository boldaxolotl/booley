- On Windows, a hung Docker command no longer stalls host Docker probes, including
  `booley doctor`, `booley bootstrap` and `booley init`, past its timeout. Booley now
  stops the Docker process and everything it started when time runs out, instead of
  waiting on output that a leftover child process still holds open
  ([#3862](https://github.com/boldaxolotl/booley/issues/3862)).

- **Breaking change:** a Simulation run now keeps its Record under new directory names:
  `targets/<Target>/campaign/` is now `targets/<Target>/record/` (the manifest you pass to
  `booley flow sim --resume-from` is now `record/manifest.json`), and each attempt's
  `coverage-campaign/` is now `coverage-record/`. Simulation records written by Booley
  0.4.0 and earlier are refused as written by an older Booley, by resume, retention and
  pruning, the Pre-Sim scan, Coverage analysis, Goal status, the Dashboard and Goal
  generated inputs; the message names the invocation directory to delete. Finish or
  discard any interrupted Simulation run before you upgrade.

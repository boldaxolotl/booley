- Simulation now stores the simulator once per build and launches every test's attempt from
  it, read-only, instead of copying it into each attempt. Booley verifies the build before each
  launch and after the process exits, and an attempt that finds a changed or extra file in it
  fails as an infrastructure error with no accepted result. A Simulation run folder written
  before this change is refused as one written by an older Booley, like a 0.4.0 one: delete it
  and start a fresh run.

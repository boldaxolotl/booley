- A refused `booley flow sim --resume-from` now names what changed since the original run,
  such as the source closures or the test suite, and prints the command for a new run with
  the same Test Runs and seeds. `--verbose` is deprecated and has no effect; the next minor
  release removes it ([#5735](https://github.com/boldaxolotl/Booley/issues/5735)).

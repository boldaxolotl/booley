- A `booley flow sim --resume-from` refused because the workload changed now lists the
  changed areas, such as the source closures or the test suite, instead of each changed
  value, and prints the command for a new run with the same Test Runs and seeds. The JSON
  detail's `mismatches` lists those areas; `mismatch_summary` and
  `derived_fingerprint_count` are gone. `--verbose` is deprecated and has no effect; the
  next minor release removes it ([#5735](https://github.com/boldaxolotl/Booley/issues/5735)).

- `booley coverage uncovered --metric` now accepts only the five scored metrics:
  `line`, `branch`, `expression`, `toggle`, and `cover_property`. Any other
  value, such as `Branch` or `fsm`, is a usage error with exit code 2 that
  lists the valid metrics; it used to print `0 uncovered points`
  ([#4921](https://github.com/boldaxolotl/Booley/issues/4921)).

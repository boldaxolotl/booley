- `booley init` no longer adds, moves or inspects a line-ending attributes rule, in or out of
  Stealth Mode. Line-ending safety rests on the repository-local `core.autocrlf=false` and
  `core.eol=lf` settings and on converting CRLF checkouts back to LF, which init still does.
  Booley sets no commit-side policy: to have Git normalize CRLF when you commit, add your own
  `.gitattributes`. A rule an earlier Booley wrote stays where it is and is no longer reported.
  To remove one, delete the `* text=auto eol=lf` line from the root `.gitattributes`,
  `.booley/.gitattributes` or `.git/info/attributes`, delete the file if nothing else is left
  in it, and commit if the file is tracked. The Doctor checks `git.attributes-policy-unknown`
  and `git.line-ending-migration` are gone, so a waiver for either now matches nothing.
  ([issue #3802](https://github.com/boldaxolotl/booley/issues/3802))

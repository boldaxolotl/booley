- ASIC synthesis now fails a run whose combinational loop survives optimization.
  Before, the loop was reported as advisory and the run passed, because the check
  that counts loops ran after technology mapping and could not trace a path
  through mapped library cells. The loop is now counted from a check that runs
  after `synth` and before mapping.
  ([#3674](https://github.com/boldaxolotl/booley/issues/3674))

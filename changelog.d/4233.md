- Fixed a simulation run hanging on a named pipe that a killed `booley flow sim --trace` run
  left at a declared `[flows.sim].trace_files` path. Every Verilator, Icarus, and Cocotb run,
  including a run without `--trace`, a traced run that cannot stream, and a Mutation Flow run,
  now removes such a pipe before the simulator starts. Only a pipe whose ownership record shows
  Booley created it is removed; other files and pipes stay.

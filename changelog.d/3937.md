- `booley projects forget` (with or without `--purge`) now withdraws the
  Project's Sandbox issuance stamp and its pending VS Code start claim, so a
  forgotten Project no longer holds a stamp or a start claim on the host, and a
  Sandbox of that Project must be reissued before it starts again. Host
  `booley doctor` warns (`host.forgotten-project-stamps`) about stamps left by
  Projects whose directory is gone and that are not in the Project Inventory,
  and names `booley projects forget --purge <root>` for each.

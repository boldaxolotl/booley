- `booley projects forget` (with or without `--purge`) now withdraws the
  Project's Sandbox issuance stamp and its pending VS Code start claim, so a
  forgotten Project no longer holds a pending start slot or a stamp on the
  host. Host `booley doctor` warns (`host.forgotten-project-stamps`) about
  stamps left by deleted Projects that are not in the Project Inventory and
  names `booley projects forget --purge <root>` for each.

- `booley measure` now runs the Project's post-setup hook (`.booley/hooks/post-setup.*`) in its
  checkout of the commit before it checks the Targets, so an input the hook builds and Git ignores
  no longer stops the measurement. A failing or timed-out hook stops it with exit 2 and names the
  hook and its log; a source still missing now says the hook is the way to build it. A Flow's
  `--baseline` checkout runs the hook too. The hook must not call `git` in a measurement.

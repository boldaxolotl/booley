- In the Sandbox, T3 Code now puts each thread's worktree under `t3-worktrees/`
  in the Main Booley Directory and runs `booley worktree prepare` on it before
  the thread's first turn; if that fails, the thread does not start.
  `booley init` now adds `/t3-worktrees/` to `.booley/.gitignore`. Until you
  rerun `booley init`, `booley doctor` warns that the pattern is missing;
  commit the updated file.
  ([#4564](https://github.com/boldaxolotl/Booley/issues/4564))

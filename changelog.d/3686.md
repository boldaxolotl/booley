- **Breaking change:** a Simulation run now names its records for the Simulation Record.
  The Record identity key `campaign_id` is now `simulation_record_id` in the manifest
  (schema `booley.simulation-campaign-manifest/v4` is now
  `booley.simulation-record-manifest/v1`), each attempt result (`booley.simulation-result/v3`
  is now `v4`), the dependency receipt (`booley.simulation-campaign-dependency/v1` is now
  `booley.simulation-record-dependency/v1`) and the manifest's `prerequisites[]` entries, and
  in the attempt, build attempt, build result, simulator bundle, executable snapshot and
  Pre-Sim evidence records (their schemas move from `v1` to `v2`) and the run-directory
  marker (key only; it has no schema). The supervised child context is now `booley.supervised-child-context/v2`, and a
  child lane's terminal causes `campaign_error` and `campaign_cancelled` are now
  `record_error` and `record_cancelled`. No old name is accepted, except that cleanup still releases a child lane a killed
  Booley 0.4.0 left behind. Simulation records
  written by Booley 0.4.0 and earlier are refused as written by an older Booley, by
  resume, retention and pruning, the Pre-Sim scan, Coverage analysis, Goal status, the
  Dashboard and Goal generated inputs; the message names the invocation directory to
  delete. Finish or discard any interrupted Simulation run before you upgrade.

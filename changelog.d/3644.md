- **Breaking change:** `booley session refresh` now rolls forward instead of rolling
  back. If the Sandbox replacement fails or is interrupted, the previous Sandbox is
  not restored: the error names the failing step and what is still running, and
  running `booley session refresh` again finishes the work. A Sandbox that uses a
  floating license now refreshes directly instead of needing `session down` first,
  and a headless Sandbox whose issuance an EDA Grant change withdrew refreshes
  directly instead of needing `session down`, `init --seed`, and `session up`.
  Upgrade note: if a refresh was interrupted, run `booley session up` or
  `booley session down` in that Project before upgrading so the old Booley can
  finish it. Afterwards the old refresh journal directory
  (`~/.config/booley/eda/session-refresh`, or under `$XDG_CONFIG_HOME/booley`) is
  ignored and can be deleted.

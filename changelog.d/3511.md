- Breaking: Goal Mode is removed. That takes away the `booley goal` command,
  the Goal MCP tools, the Dashboard Goal and proposal views, the `booley-goal`
  skill, Goalset seeding by `booley init`, `[goals].quiet_after`,
  `booley cheat --goals`, and the Goal Mode guide. `booley measure` and
  Metric-Driven Development replace it. A `[goals]` section in `booley.toml`
  now makes every command that works on a Project except `booley doctor`,
  `booley upgrade`, `booley session` and `booley chat` refuse and name the
  section and its lines, and `booley doctor` reports a FAIL
  (`config.retired-goals`):
  `delete the [goals] tables (lines a-b) from <path>; Goal Mode was removed`.
  Delete the tables, or type `/booley-heal` in a Developer Agent chat to remove
  them. `booley measure` still measures an older commit whose own
  `booley.toml` has the section.
  `goals/` and `goalsets/` directories left by earlier versions are neither
  read nor deleted; Doctor warns about them (`goals.leftover`), so delete them
  when you no longer need their records.
  ([issue #3511](https://github.com/boldaxolotl/booley/issues/3511))

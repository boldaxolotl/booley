- `booley init` now writes `.booley/metrics.toml` with the default test bounds and
  no table, so a Project can adopt metrics later. It never overwrites an existing
  file. Project Setup asks whether to enable metrics now or later (default
  later), and Project Setup and `/booley-heal` add one `AGENTS.md` pointer to
  `booley cheat --metrics` when it is missing.
  ([issue #4136](https://github.com/boldaxolotl/booley/issues/4136))

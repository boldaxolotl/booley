Candidate seam

decode_coverage_campaign(document, expected_target) -> CoverageCampaign is the one external operation. It accepts already-read JSON, returns one immutable typed campaign, and reports all structural and semantic findings together with stable codes and JSON Pointers. File I/O, native parsing, policy configuration, and report rendering stay outside this interface.

Deliberate distinction: a document can be schema-valid while recording a collector error, incomplete evidence, failed Criterion, or incompatible native format. Validation asks whether the document tells the truth consistently—not whether coverage passed.

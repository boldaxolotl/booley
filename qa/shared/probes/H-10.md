# H-10 disposable probes

`doctor-plain`, `doctor-deep`: run separately → current structured last.json and complete last.log, intended selected checks. `doctor-warning`: benign warning fixture → actionable warning. `waiver-valid`: add explicit unexpired matching waiver → warning waived. `waiver-expired`, `waiver-stale`: expire/change warning identity separately → waiver no longer applies. `failure-not-waivable`: hard config failure with waiver → remains failure. `health-stale`: change config → freshness reports stale. `doctor-recovery`: restore config/run Doctor → fresh clean health.

Evidence and recovery: Separate report/log copies before overwrite, waiver text with expiry, config diffs. Deep Doctor retains manually suggested FPGA command rather than silently claiming FPGA execution.

# I-01 disposable probes

`client-session`: actual selected VS Code client calls status/targets/Flow/Specialist → runtime identity and durable interactive logs; no Ticket/Criteria created. `interactive-commit`: safe edit/commit → exact local diff/history. `bare-launch`: bare booley/chat → configured provider and Project cwd. `bare-launch-failure`: missing disposable client executable → actionable diagnostic. `bare-launch-recovery`: restore executable → native CLI launches.

Evidence and recovery: Supported-client transcript is required for client coverage; shell/MCP harness cannot replace it. Provider compatibility executions remain separate.

# H-03 disposable probes

`init-repeat`: repeat plain init → no unintended file/spec drift. `init-check`: check-only on stale disposable state → reports work without mutation. `init-force`: force reconcile owned generated state → issued configuration restored, user sentinel intact. `seed`: init with declared seed → seeded policy/config appears. `skip-credentials`: initialize with skip flag → no credential mutation. `location-guard`: invoke host-only init inside runtime → actionable rejection. `provider`: select each provider in separate declared compatibility run → issued auth/client policy matches selection.

Evidence and recovery: Generated config/devcontainer, sanitized policy, hashes. Windows: `lf-auto` introduces clean CRLF fixture → local Git policy and LF reconciliation; `lf-compat` repeats with compatibility flag → accepted; `lf-dirty`, `lf-protected`, `lf-hardlink` each introduces named unsafe file class → refusal without changed bytes. `lf-recovery`: remove unsafe fixture condition and retry → normalized safe file.

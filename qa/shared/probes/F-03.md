# F-03 disposable probes

`synth-metrics`: execute assigned mode/frontend → fresh metrics and actual tool provenance. `synth-latch`: bounded latching fixture → reported critical condition. `synth-advisory`: timing miss without hard threshold → advisory. `synth-threshold`: configured threshold violated → design failure. `synth-baseline`: compare declared baseline/candidate → numeric delta with both identities. `synth-frontend-missing`, `synth-frontend-incompatible`: distinct faults → appropriate config/execution failure. `synth-recovery`: restore supported frontend/design → valid fresh metrics.

Evidence and recovery: Yosys/OpenROAD/frontend logs and versions, SDC/default clock, selected profile/expert override, metrics/baseline recipe. No signoff claim.

# S-06 disposable probes

`threshold-absolute`: declared absolute count/PPA bound → computed pass/fail from exact metric. `threshold-relative`: baseline-relative bound → exact delta. `threshold-directed`: baseline/candidate Target pair → role direction retained. `threshold-clock`: named-clock bound → only declared clock metric. `baseline-missing`, `baseline-mismatch`: absent/incompatible basis → fail closed. `baseline-recovery`: restore exact compatible basis → evaluated result.

Evidence and recovery: Both refs, Target recipes, numeric operands and result; no generic report-exists oracle.

# F-04 disposable probes

`fpga-dry`: dry-run → exact part/top/XDC/source inventory without implementation. `fpga-fresh`: implementation → routed timing/utilization and fresh artifacts. `fpga-cache`: same inputs → authenticated cache hit. `fpga-no-cache`: same inputs no-cache → actual fresh EDA tool execution. `fpga-design-fail`: declared bad design/threshold → rc1 design result. `fpga-authority-fail`: remove run-owned Grant → rc2 without unauthorized execution. `fpga-baseline`: declared pair → exact metrics delta/provenance. `fpga-recovery`: restore authority/design → valid implementation.

Evidence and recovery: Vivado 2025.2 log, source/cache keys, routed reports and baseline identities; Windows expected not runnable.

# H-09 disposable probes

`profile-crud`: register/list/show disposable License Profile → same safe identity. `profile-attach`: attach to exact Grant → Session Runtime policy matches authorized destination. `relay-isolation`: controlled relay infrastructure attempts unapproved destination → blocked. `relay-failure`: make approved controlled destination unavailable → precise diagnostic without leaked secret. `relay-recovery`: restore controlled endpoint → approved route usable. `profile-cleanup`: detach/remove owned profile and relay → no owned resources remain.

Evidence and recovery: Redacted registry/Grant/Session Runtime policy, destination, and cleanup evidence. Actual paid checkout/accounting/concurrency/return are optional experimental checks with per-run site authority; never inferred from relay success.

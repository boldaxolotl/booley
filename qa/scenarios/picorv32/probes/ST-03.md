# ST-03 disposable probes

`sanitize-word`, `sanitize-trailer`: separate benign banned token/trailer commits → rewritten as documented. `subject-reject`, `body-reject`: invalid convention/overlong body → refused, not truncated. `escape-sanitized`: documented environment escape → convention/body bypass but sanitization remains. `push-identity-allow`, `push-identity-reject`: disposable local remote and identities → respective allow/reject. `push-path-reject`, `push-symlink-reject`: banned path/target → rejected. `push-guard-escape`: documented guard escape on disposable local remote → documented bypass only.

Evidence and recovery: Commit messages/diffs, hook output and exact local remote; no public push. `history-recovery`: restore compliant inputs → valid local commit/push and no unsafe files.

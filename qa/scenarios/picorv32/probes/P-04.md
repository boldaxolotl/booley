# P-04 disposable probes

`sentinel-pass`, `sentinel-fail`, `sentinel-both`, `sentinel-none`: fixture emits each combination → pass, fail, fail, inconclusive respectively. `test-token`: select one plusarg/getopt token → exactly named test executed. `skip-default`: default run → skipped test absent. `skip-override`: explicit selection → same test runs. `cycle-valid`: emit named count → exact parsed count. `cycle-invalid`: malformed/missing count → cannot satisfy Criterion.

Evidence and recovery: Per-test verdicts and raw logs; `sentinel-recovery` restores valid fixture → pass; malformed count is not silently zero.

# P-02 disposable probes

`target-views`: list/filter/detail/JSON/MCP same targets → same qualified identities and typed values. `target-qualified`: invoke collision fixture with qualified name → exact core selected. `target-ambiguous`: bare collision → rejected. `target-refresh`: edit owned core then refresh → new target values visible. `target-parameters`: execute two declared Targets with different values → respective values appear in reports. `target-override`: supply invented per-call parameter override → rejected.

Evidence and recovery: Core manifests, discovery outputs, resolved build inputs; `target-recovery`: restore valid qualified selector → Flow completes with expected identity.

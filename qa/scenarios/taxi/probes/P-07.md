# P-07 disposable probes

`derived-image`: bake pinned requirements → runtime dependency versions match image identity. `dependency-refresh`: change permitted dependency pin → stale image detected and rebuilt identity used. `runtime-offline`: attempt runtime dependency acquisition → no undeclared network install. `host-skill-readonly`: opt in disposable skill → visible but write denied. `hook-once`: new Ticket workspace with bounded hook → exactly one successful invocation; resume → no repeat. `hook-failure`: controlled nonzero hook → workspace blocked. `hook-recovery`: fix fixture and documented retry → usable workspace.

Evidence and recovery: Image/pip manifests and payload provenance, skill mount metadata, hook counter/log and workspace identity.

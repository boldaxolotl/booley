# W-03 disposable probes

`query-list`, `query-signal`, `query-wave`, `query-value`, `query-find`, `query-sample`, `query-diff`, `query-distance`, `query-stats`, `query-stuck`: each command on deterministic known trace → exact hierarchy/value/time/statistic oracle. `query-pattern-miss`, `query-ambiguous`, `query-limit`: absent pattern, colliding name, bounded output → documented results. `version`, `legacy-translation`, `schema`, `docs-list`, `docs-search`, `docs-show`, `skill`: each public/meta route → installed coherent content or equivalent translated query.

Evidence and recovery: Ground-truth event table fixed independently from B-Wave outputs, each output and schema-supported envelope. JSON and virtual shared matrices are mandatory additional per-command checks.

See [B-Wave command matrices](../../../shared/probes/bwave-matrices.md).

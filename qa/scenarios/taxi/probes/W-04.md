# W-04 disposable probes

`sync-event`, `async-event`: same known edge → post-edge cycle and raw transition correctly related. `clock-override`: ambiguous clocks with explicit choice → correct sampling. `reset-include`, `reset-skip`: each mode → correct sample set. `time-units`: equivalent physical/cycle/tick tokens → same known event. `literal-slice`: valid Verilog literal/bit slice → expected value. `async-bare-time`, `bad-literal`, `unknown-signal`, `width-mismatch`: independent invalid inputs → documented errors.

Evidence and recovery: Oracle table, clock/reset metadata, exact inputs/output. `query-input-recovery`: corrected inputs → expected event; virtual semantics shared matrix applies.

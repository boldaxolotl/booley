# T-11 disposable probes

`human-policy`: unattended configuration → no manufactured live approval. `report-policy-required`, `report-policy-optional`: separate runs → configured required report or explicit justified no-report result. `timeout-active`, `timeout-wall`: controlled wait/work fixture → configured active versus wall accounting. `model-tier`, `model-role`: independently override tier/role → execution metadata records selected model. `model-invalid-role`, `limit-invalid`: malformed inputs → rejected before Developer Agent work.

Evidence and recovery: Sanitized configuration, elapsed/accounted times and durable provider/model metadata; `policy-recovery`: restore valid config → launch succeeds.

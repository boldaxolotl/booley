# P-01 disposable probes

`setup-plan`: invoke the published Project Setup route for an existing or new Project → one complete approved plan before changes. `setup-conformance`: compare resulting configuration/cores/guidance to plan → each deviation explicit. `setup-native`: execute accepted native-host parity comparison → baseline and Project Setup result compared. `setup-findings`: invoke required Findings handoff → retained local report. `setup-selector-docs`: compare public selector lists → mismatch retained as docs Finding if present.

Evidence and recovery: Approved plan, public route citations, generated diff, native logs and Finding record; no source-assisted workaround before capture.

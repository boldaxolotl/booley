# W-02 disposable probes

`alias-register`: register file/sim directory → alias and _last resolve expected absolute path. `alias-restart`: restart context → same mappings queryable. `alias-replace`: replace alias → new path returned. `marker-create`, `marker-list`, `marker-delete`: manipulate named marker → exact persisted state. `trace-same-path`: regenerate trace in place → new mtime/data recognized. `alias-missing`: missing path → error. `alias-stale`: older trace → warning.

Evidence and recovery: Registry snapshots, paths/registration times/mtimes and queried values; identity is replaceable path, not immutable content-addressing.

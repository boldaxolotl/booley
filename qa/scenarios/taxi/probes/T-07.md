# T-07 disposable probes

`success-review`, `success-done`: configured destinations → exact destination and expected merge/cleanup. `run-result`: review run → parse stable BOOLEY_RUN_RESULT. `briefing-json`: regenerate unchanged briefing → deterministic versioned JSON. `briefing-html`: request rich output → generated artifact. `briefing-html-failure`: induce owned renderer/output fault → accepted work unchanged. `briefing-regenerate`: repair fault → rich artifact restored without rerunning accepted work.

Evidence and recovery: Board/history/worktree disposition, machine record, briefing copies/hashes and renderer diagnostic.

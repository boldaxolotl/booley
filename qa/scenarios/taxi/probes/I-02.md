# I-02 disposable probes

`mcp-schema`: discover MCP tools through each actual supported Runtime Attachment → public argument contracts. `detached-poll`: long public Job returns run_id then poll → same Job terminal result. `report-timeout`: inline caller timeout then report lookup → latest same durable report. `cancel-queued`, `cancel-running`: cancel each state → distinct cancelled outcome, not design/infra failure. `cancel-recovery`: new Job afterward → queue usable and clean completion.

Evidence and recovery: run_id, timing, reports, queue/running snapshots and process cleanup.

# I-02 disposable probes

`mcp-schema`: discover tools in each actual supported client → public argument contracts. `detached-poll`: long public job returns run_id then poll → same job terminal result. `report-timeout`: inline client timeout then report lookup → latest same durable report. `cancel-queued`, `cancel-running`: cancel each state → distinct cancelled outcome, not design/infra failure. `cancel-recovery`: new job afterward → queue usable and clean completion.

Evidence and recovery: run_id, timing, reports, queue/running snapshots and process cleanup.

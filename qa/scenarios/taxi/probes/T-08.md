# T-08 disposable probes

`checkpoint-interrupt`: interrupt after completed Booley Flow → checkpoint retained. `checkpoint-resume`: restart → no duplicate accepted evidence. `subscription-requeue`: safely controlled subscription-limit fixture → waiting/requeue. `known-transient-retry`: configured known stream-stall fixture → bounded retry. `ordinary-crash`: different crash signature → no unjustified retry. `developer-timeout`: bounded timeout fixture → distinct timeout outcome.

Evidence and recovery: Checkpoint/run IDs, classifications, attempt counts, public configuration and cleanup. Real human-block behavior is T-03; safe public fault induction must be implemented explicitly, never by depleting real quota.

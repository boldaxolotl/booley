# T-03 disposable probes

`transition-queue`, `transition-run`, `transition-review`, `transition-done`: normal Ticket → each exact state transition. `dependency-wait`, `dependency-release`: unmet then completed dependency → waiting then queued. `human-block`, `human-unblock`: explicit blocker and real human feedback → blocked then queued. `resume-workspace`: resume → same Ticket, preserved branch commits and evidence; rebuilt disposable checkout is identified from canonical state, not treated as lost work merely because path changes. `done-shortcut`: explicitly authorized successful destination → running to done.

Evidence and recovery: Board snapshots, transition logs and stable workspace identity; never fabricate human response during unattended operation.

# W-05 disposable probes

`gui-scoped`: query known event then scoped open → trace identity, clock row 1, exact signals, range markers and cursor. `gui-append`: append signal → old rows retained plus exact new row. `gui-dropped`: request unsupported/dropped viewer signal → warning and readback discrepancy explicit. `gui-no-clock`: no-clock → no automatic clock. `gui-cap`: small max-signals → documented cap. `gui-no-wcp`: unavailable WCP with scoped request → failure. `gui-bare-fallback`: bare GUI without WCP → documented editor fallback. `gui-recovery`: restore qualified observer/WCP → exact scoped view verified.

Evidence and recovery: WCP readback plus rendered screenshot from qualified observer, before/after each state change. Unavailable observer remains unavailable profile, no CLI substitute.

# P-10 disposable probes

`custom-discover`: install deterministic public Custom Flow/endpoint and Criterion → advertised schema. `custom-preflight`: dry-run → validated inputs/no execution artifact. `custom-criterion`: run → report satisfies its bound custom Criterion. `custom-disabled`: disable endpoint → absent from discovery. `custom-invalid`: syntax/schema fault → Doctor identifies extension failure. `custom-recovery`: restore file/re-enable → discovery and report succeed.

Evidence and recovery: Extension fixture source, public schema, Doctor output and Criterion/report binding; never substitute custom result for built-in sim.

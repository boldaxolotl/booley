# H-11 disposable probes

`upgrade-pending`: create Project using immediately preceding published release then install the exact declared target build → pending review identifies endpoints. The target may be a published release or an immutable unreleased candidate. `upgrade-heal`: documented heal/health/Runtime Image reconciliation → current declared payload and clean health. `upgrade-ack`: acknowledge exact verified target → no pending change.

Evidence and recovery: Preceding release and target-build package identities, Runtime Image payloads, health reports and upgrade state before/after. No acknowledgement following unsuccessful repair.

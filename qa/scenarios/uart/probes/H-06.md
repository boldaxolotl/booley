# H-06 disposable probes

`runtime-up`: absent runtime→up/status/validate → running issued spec. `enter-success`: child returns zero → zero. `enter-failure`: child returns nonzero → same nonzero. `interrupt`: interrupt supervised child with descendant → signal semantics preserved and descendants gone. `refresh`: change permitted image/spec then refresh → new immutable identity. `refresh-rollback`: inject bounded replacement validation failure → old runtime restored. `refresh-vscode`: try refreshing VS Code-owned runtime → refusal, runtime unchanged. `runtime-down`: down → absent/stopped and no owned descendants.

Evidence and recovery: Runtime IDs/spec digest/process listing before/after. `runtime-retry`: repeat up/enter after interruption → usable clean runtime on both OSes. VS Code: `legacy-replace` exactly one authenticated legacy container → only it replaced; `legacy-refuse-ambiguous`, `legacy-refuse-foreign`, `legacy-refuse-headless`, `legacy-refuse-multiple` → each refused with all other identities intact; `legacy-poststop-failure` → exact restart command after validation failure; `legacy-restart` → supplied command restores usable runtime, named volumes unchanged.

# H-06 disposable probes

`runtime-up`: absent Session Runtime→up/status/validate → running issued spec. `enter-success`: child returns zero → zero. `enter-failure`: child returns nonzero → same nonzero. `interrupt`: interrupt supervised child with descendant → signal semantics preserved and descendants gone. `refresh`: change permitted Session Image/spec then refresh → new immutable identity. `refresh-rollback`: inject bounded replacement validation failure → old Session Runtime restored. `refresh-vscode`: try refreshing VS Code-owned Session Runtime → refusal, Session Runtime unchanged. `runtime-down`: down → absent/stopped and no owned descendants.

Evidence and recovery: Session Runtime IDs/spec digest/process listing before/after. `runtime-retry`: repeat up/enter after interruption → usable clean Session Runtime on both OSes. VS Code: `legacy-replace` exactly one authenticated legacy container → only it replaced; `legacy-refuse-ambiguous`, `legacy-refuse-foreign`, `legacy-refuse-headless`, `legacy-refuse-multiple` → each refused with all other identities intact; `legacy-poststop-failure` → exact restart command after validation failure; `legacy-restart` → supplied command restores usable Session Runtime, named volumes unchanged.

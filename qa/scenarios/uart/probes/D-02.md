# D-02 disposable probes

`feedback-file-only`: unattended report generation → file only/no outbound send. `feedback-redact`: benign planted private-like fixture → exact intended redaction in preview. `feedback-token`: approved preview token then rerender changed content → old token rejected. `feedback-export`: explicit local export → preview-equivalent file. `feedback-block-submit`: dry-run/unconfirmed submission → nothing sent. `feedback-off`: off mode → no outbound offer.

Evidence and recovery: Exact sanitized preview/export and confirmation metadata without secrets; actual issue/mail send remains outside these probes.

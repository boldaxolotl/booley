# H-02 disposable probes

`pending`: bootstrap check-only before reconciliation → rc1 and no mutation. `automatic`: plain init without prior bootstrap → managed resources reconciled. `ready`: check-only afterward → ready without mutation. `idempotent`: repeat bootstrap → stable identities. `force-repair`: safely stale one run-owned managed resource and force → repaired resource, preserved caches/user sentinel.

Evidence and recovery: Before/after resource identities, image/PDK/skill links and user-file hashes; `repair-ready`: subsequent check-only succeeds.

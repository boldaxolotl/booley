# H-12 disposable probes

`config-defaults`: absent disposable host config → documented defaults. `config-idle`, `config-cap`, `config-egress`: separately override each supported field → observed timeout, cross-Project cap, and allowed hostname. `config-denied-egress`: undeclared host → blocked. `config-invalid-scheme`, `config-invalid-path`, `config-invalid-port`, `config-invalid-ip`, `config-invalid-wildcard`, `config-invalid-key`: each input → validation rejection before bootstrap mutation. `config-preserve`: successful and rejected reads → byte-identical host config. `config-recovery`: restore valid policy → bootstrap succeeds.

Evidence and recovery: Policy hashes, admission timestamps/runtime counts, controlled network results and owned-resource snapshots; no unrelated external targets.
